# CLR Catch

V2-only baseline provenance: this sample is written for exceptions Requirements 5
and 1.12, after classic was retired. Its stdout is captured from the standard
pipeline and checked against the programs, then banked through AllFeaturesV2.

The C# companion supplies deterministic foreign invocation, completion and
cancellation failures with stable exception objects. The Mist programs demonstrate
method groups, a stored delegate, lambdas, once-only receiver/callable/argument
preparation, void, nested Results, actual File calls, Error propagation, cancellation
identity and normal adapter completion, raw task cancellation, deferred iteration
and later disposal. The companion is a project reference, not a second runner.
