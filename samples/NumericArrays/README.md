# Numeric and array capabilities

Exercises nullable parsing, numeric bound fields, comparison, floating predicates and bit stepping,
provider formatting and invariant round trips. Array calls cover first-match and absence handling,
matched zero, predicate order and short-circuiting, conditional access, generic optional results,
ordinal comparer sorting and empty literals. Native async expressions and blocks join started
operations through the existing value and resultless WhenAll contracts.

This sample is V2-only. Its baseline was captured from the standard pipeline and checked against
the program's numeric values, array contents and visit counts. AllFeaturesV2 banks its output.
The signature contract and production mappings are in
[the standard-library specification](../../specs/standard-library/self-host-capabilities.md).
